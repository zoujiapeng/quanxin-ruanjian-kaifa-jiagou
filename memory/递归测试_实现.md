## 实现方式

Claude Code 不能自 spawn 新 Claude Code 实例。递归测试通过 Lobster 项目能力实现：

1. **Lobster 生成脚本** — 用 Python 写一个 pipe prompt 到 `claude -p` 的脚本
2. **打开终端** — 用 `launch_program` 打开新终端窗口运行该脚本
3. **新 Claude 干活** — 终端里的 claude 收到 prompt，使用 lobster_* MCP 工具执行任务
4. **prompt 内容** — 必须是"其他项目做不到的"GUI 自动化闭环（进程管理 + 窗口操作 + 键盘输入 + 截图 + OCR）

**技术要点:**
- lobster MCP 已通过 `claude mcp add` 注册到全局 project 配置（在 `.claude.json` 中）
- 新 Claude 从 `C:\Users\zou\Desktop\claude1` 启动能自动发现 107 个 lobster_* 工具
- 终端里的 claude 输入中文没问题
- 用 Python 脚本而非 `.bat` 文件来避免 GBK 编码问题

**MCP 注册方式（已配置）:**
```bash
claude mcp add lobster -- python C:\Users\zou\Desktop\claude1\cli\lobster_mcp.py
```
