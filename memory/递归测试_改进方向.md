## 改进方向

### 1. 强制 MCP 工具路径，不走 Bash
- 新 Claude 默认会选择 CLI（`lobster.py call`）而非 MCP（`lobster_*`）
- CLI 触发 Bash 权限审批，打断自动化流程
- MCP 工具走 MCP 协议，不需要权限审批
- **改进**: prompt 必须明确写 "只使用 lobster_* MCP 工具，禁止使用 Bash/python 命令"

### 2. 任务要设计成"只有 Lobster 能做到"
- 普通 LLM 也可以回答"怎么启动记事本"这类问题
- 但 LLM **不能** 截图、OCR 识别、检测颜色、找图像模板、监控进度条
- **改进**: 任务必须包含 Lobster 独有的感知层能力（screenshot + ocr_find_text / detect_color / find_image / detect_progress），这些才是同类项目做不到的事

### 3. 验证是否真正用了项目
- 看新 Claude 的调用记录，确认它调用了 lobster_screenshot、lobster_ocr_find_text 等感知层 MCP 工具
- 如果只用 type_text + hotkey，那和普通 pyautogui 脚本没区别
- 真正的递归测试验证的是 "感知→决策→动作→验证" 闭环
